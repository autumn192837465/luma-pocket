# Luma Pocket

Luma Pocket 的 App 支援與隱私權政策網站，以 GitHub Pages 發布（純靜態 HTML，無建置步驟）。

| App | 隱私權政策 | 使用支援 |
| --- | --- | --- |
| QR 掃描製作器（Quick QR: Scan & Create）`com.kinopistudio.quickqr` | `quick-qr/privacy.html` | `quick-qr/support.html` |

新增 App 時，建立 `<app>/privacy.html` 與 `<app>/support.html`，並在 `index.html` 加入連結。每份隱私權政策都要寫出與商店資訊一致的 App 名稱、開發人員名稱 Luma Pocket 與套件名稱，否則 Google Play 會判定「應用程式或開發人員詳細資料不相符」。
